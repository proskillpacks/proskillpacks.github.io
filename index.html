How we test

A skill is only useful if its output is right. This is the bar every skill has to clear before it goes on sale.

1

Real data only

Each skill runs on real public stores, products, reviews and policies. No made-up cases.

2

Scored against a rubric

Every run is scored out of 10 on written criteria. Any invented fact is a fail.

3

Ships at 8 or better

A skill is released only when every test scores 8/10 or more. If one fails, we fix it and test again.

4

Fixed for everyone

If an output is wrong, tell us what you gave it. Fixes go to every buyer.
